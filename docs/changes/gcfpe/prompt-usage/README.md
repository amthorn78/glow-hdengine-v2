# Prompt-use ledgers

Authorized repository writers place actual per-change metadata ledgers here as `<change-id>.json`. No observed ledger is supplied by alpha establishment: no real change flow was executed.

These ledgers retain actual runtime-resolved versions and identities as historical records outside prompt bodies. Reusable prompt instructions instead locate sources by versionless names and verified directory paths; do not copy ledger links, provider IDs or source-version pins into them.

See [GCFPE prompt-use provenance](../../GCFPE_PROMPT_PROVENANCE.md) for capture ownership, field meanings, validation and exact component lookup. The non-development example is in `tests/qa/fixtures/gcfpe/` so it cannot be mistaken for an observed change ledger.
