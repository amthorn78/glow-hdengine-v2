## C040-06 — Approved decision

**Classification: NEW_CANON. Status: APPROVED. Alternative: A, exactly as originally proposed and approved.**

### Source question and conflict

The existing Channel schema's closed vocabulary does not itself prove any Channel's exact circuit/substream assignment. The catalog before-state contains incorrect primary/substream values and null substreams. Older formal teaching places Integration structurally apart from the six formal circuits, while official broad-group exposition includes Integration in Individual. Both distinctions must be preserved. Gate captions and a diagram connecting shared Gates cannot classify every incident Channel as Integration.

HDE-Schemas & Artifacts §2.1 owns the Product topology schema, field vocabulary and metadata boundary. HDE-Math-Spec §§6.1–6.2 owns the already adopted relationship-state predicates and hanging-Gate derivation. The original ADR's complete source ledger and row records supply the source-specific classification facts. Research establishes evidence, not approval; the exact independent decision is identified above.

### Exact approved substance

1. Adopt the complete thirty-six-row assignment table below for the existing Channel Catalog contract, preserving the closed roster and numeric-ascending, zero-padded Channel identity.
2. Define circuit_primary as the Product's broad grouping for these rows: individual, collective or tribal. The existing typed substream label does not claim that a circuit, a stream and the Integration system are identical doctrinal levels.
3. Encode only 10-20, 10-57, 20-34 and 34-57 as individual/integration. Preserve Integration's separate formal structural taxonomy alongside the broad Individual Product encoding.
4. Preserve 10-34 as individual/centering and 20-57 as individual/knowing. Channel-specific evidence controls these exceptions.
5. Derive each Channel's Center set from its two authoritative Gate facts. The Center array is a set, not a positionally aligned Gate/Center tuple; retain the nine canonical Center IDs.
