## Token definitions
- CLI_NO_ALT_JSON_OK: hdctl showcompat emits canonical JSON only; see `cli.showcompat.summary`.
- CLI_READER_PARITY_OK: CLI/Reader outputs match (`cli.showcompat.reader_cli_parity`).
- CLI_SHOWCOMPAT_CANON_OK: canonical emitter used for compatibility outputs (`cli.showcompat.summary`).
- CLI_STDOUT_LF_OK: LF-terminated stdout (`cli.showcompat.summary`).
- JSON_CANONICAL_CHECK_OK: canonical JSON across CLI/registry/ordering (`cli.showcompat.ab`, `registry.registry_report`, `engine.order.props_total_order.log`).
- TWO_RUN_IDENTITY_OK: two-run identity + preimage recompute (`cli.showcompat.preimage_recompute`).
- COMPOSITE_ABBA_IDENTITY_OK: AB↔BA identity across composite outputs (`engine.order.abba_identity.bytes`).
- CONFIG_GEN_OK: registry_report.v1 generated by typed loader (`registry.registry_report`).
- UNKNOWN_IDS_FAIL_CLOSED_OK: registry loader rejects unknown IDs (`registry.registry_report`).
- TIEBREAK_TOTAL_ORDER_OK: ordering comparators deterministic (`engine.order.props_total_order.log`).
- EVIDENCE_INDEX_UPDATED_OK / MACHINE_MIRROR_UPDATED_OK / EVIDENCE_INDEX_HASH_OK / EVIDENCE_INDEX_MIRROR_OK: mirror self-record updated with hash+size (`index.machine_mirror`).
- EVIDENCE_PATHS_VALIDATED_OK / EVIDENCE_PATH_PROOFS_OK: path proofs present and validated (`topology.orientation_demo`).
- CI_CHECK_MIRROR_SCHEMA_OK / CI_CHECK_FINAL_LF_OK: CI gates on mirror schema and LF discipline (mirror self-record, CLI canon).
- DOC_DELTA_PRESENT_OK: PF doc-deltas staged under `audit/docdeltas/`.
- TESTS_PASS_OK: QA suite recorded in `qa.compat.coverage_summary`.
