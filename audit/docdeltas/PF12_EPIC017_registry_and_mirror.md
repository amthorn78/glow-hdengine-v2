# PF12 — EPIC017 registry & mirror notes (paste-ready)

## Registry report
- Schema: `registry_report.v1`; canonical JSON (UTF-8, sort_keys, compact, trailing LF).
- Production path: `artifacts/registry/registry_report.json` with `.path_proof.txt` and mirror entry `registry.registry_report`.
- Generated by the typed loader (see tools/generate_registry_report.py) under SAFE_MODE=1 ALLOW_NETWORK=0 LC_ALL=C LANG=C TZ=UTC.
- Unknown IDs fail closed; aliases resolved before validation; two-run identity enforced in tests.

## Machine mirror and self-record
- Mirror file: `artifacts/evidence_index.jsonl` with self-record key `index.machine_mirror` (role=self_record).
- Self-record sha256 hashes over all other entries (body-only) and stores size_bytes for the full mirror; path proof records `mtime_utc` at refresh time (monotone, not expected to equal later stat()).
- Proof schema: path, size_bytes, sha256, mtime_utc, produced_at_utc (lines with colon separators; LF-terminated).

## Human index normalization
- `docs/evidence/INDEX.json` holds `{artifact_key, discovered_physical_path}` objects sorted by artifact_key/path; duplicates deduped before render.
- `docs/evidence/INDEX.sha256` is the hash sentinel over the rendered human index and is NOT mirrored.

## Orientation demo / path proofs
- `topology.orientation_demo` remains the exemplar for path-proof validation and topology evidence; include it in PF12 tables.

## Commands
- Refresh sequence: update `docs/evidence/INDEX.json` → run `python tools/evidence/update_evidence_index.py` (writes HASH, mirror, path proofs) → run CI mirror schema check.
