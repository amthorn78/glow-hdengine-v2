# PR02 Remediation Session Diff Report

## Scope
This session remediated CLI version output behavior from the latest commit and regenerated governed evidence artifacts impacted by that behavior.

## Code Changes

### 1) `engine/cli/main.py`
- Replaced argparse `action="version"` behavior with explicit CLI pre-parse handling in `cli()`.
- Added `_cli_version_text()` helper to construct deterministic one-line version output.
- Added explicit `--version` conflict guard: when combined with other args/subcommands, CLI exits `64` with `VERSION_FLAG_WITH_COMMAND`.
- Kept `--version` present in help surface via parser option declaration.

### Why this was changed
The previous implementation emitted wrapped multi-line version output in this environment, which weakened strict CLI conformance evidence. The new path emits an exact single-line stdout payload for `python -m engine.cli --version` and maintains deterministic behavior.
