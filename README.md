# Glow HD Engine — Post-EPIC022 documentation sweep

The Glow HD Engine is a deterministic Human Design engine and CLI that emits governed, canonically serialized bytes. PF-Canon remains authoritative (titles only: PF05 — CLI/API/Vendor Ref, PF12 — Schemas & Artifacts, PF14 — Mechanics Guide, PF19 — QA Guide, PF20 — Phased Epics).

## Overview

- Public Reader v1 and CLI share the canonical emitter and serializer; AB↔BA and two-run identity proofs cover public bytes.
- Error responses use the canonical `error_v1` envelope with typed error tokens and JSON discipline under closed rails.
- Evidence posture is governed: human Evidence Index under `docs/evidence/INDEX.json`, machine mirror under `artifacts/evidence_index.jsonl`, and `.path_proof.txt` siblings for governed artifacts.
- What EPIC022 tightened:
  - D1: error-envelope parity scenarios remain closed-rails first, with deterministic refusal coverage and env-pin gating.
  - D2: showcompat canonical stdout capture is generated deterministically with indexed artifacts and sha256 sidecars.
  - Acceptance scaffolding now anchors EPIC022 token matrix and acceptance map bindings to concrete evidence and tests.

## Quickstart (closed rails default)

Closed rails are required for CLI and evidence runs: `SAFE_MODE=1 ALLOW_NETWORK=0 LC_ALL=C LANG=C TZ=UTC`.

```bash
python -m pip install -e .

# CLI help
SAFE_MODE=1 ALLOW_NETWORK=0 LC_ALL=C LANG=C TZ=UTC python -m engine.cli --help

# Compat output via showcompat (stdout on success; stderr on errors)
SAFE_MODE=1 ALLOW_NETWORK=0 LC_ALL=C LANG=C TZ=UTC hdctl showcompat --a-file fixtures/charts/alice.json --b-file fixtures/charts/bob.json

# Aux narrative preview for a compat tuple (admin/test)
SAFE_MODE=1 ALLOW_NETWORK=0 LC_ALL=C LANG=C TZ=UTC hdctl aux-preview --pair-file artifacts/presenter/showcompat_identity_summary.json --category undefined --band Cool --perspective shared --show-narrative
```

- Dev Reader helper (`scripts/dev_start_reader.sh`) remains available for dev/test/local harnessing; APP_ENV gating applies.
- Use the determinism helper (`engine.runtime.determinism_env.ensure_determinism_env`) or `ci/checks/check_env_pins.sh` to confirm pins.

## CLI usage (verified)

- Entry point: `hdctl` (or `python -m engine.cli`).
- Subcommands: `showcompat`, `aux-preview`, `bg:resolve`, and dev-only `dev:sampler` (APP_ENV=dev).
- `showcompat` accepts `--pair-file`, `--a-file/--b-file` (aliases `--a/--b`), stdin, or birth arguments; success prints LF-terminated canonical JSON to stdout, errors print `error_v1` envelopes to stderr. Sidecars: `--dump-reader`, `--dump-admin-dir`.
- Deterministic artifact generator: `python tools/cli/generate_showcompat_artifacts.py` captures `artifacts/cli/showcompat/stdout.json`, `artifacts/cli/showcompat/stdout.json.sha256`, and `artifacts/cli/showcompat/args.json` under closed rails.
- `aux-preview` previews Aux narrative ids/text for compat tuples using the sealed narrative pack.
- `bg:resolve` is a Phase S8a stub for BodyGraph resolution with `--source {db,vendor,auto}` under closed rails.

## Evidence & determinism (operator-level)

- Evidence Index (human): `docs/evidence/INDEX.json`; sentinel hash: `docs/evidence/INDEX.sha256`.
- Machine mirror: `artifacts/evidence_index.jsonl`; governed artifacts include `.path_proof.txt` siblings.
- Showcompat D2 artifacts: `artifacts/cli/showcompat/stdout.json`, `artifacts/cli/showcompat/stdout.json.sha256`, `artifacts/cli/showcompat/args.json` (generated by `tools/cli/generate_showcompat_artifacts.py`).
- Orientation and sanity checks: `python tools/evidence/orientation_demo.py` and `python tools/evidence/run_sanity_pipeline.py` (closed rails).
- Registry report: `python tools/generate_registry_report.py` → `artifacts/registry/registry_report.json`.
- Evidence index updater: `python tools/evidence/update_evidence_index.py` refreshes Index/Mirror bindings after regenerating governed artifacts.
- EPIC022 acceptance scaffolding: `docs/acceptance_map_epic022.json` and `audit/qa/hde-epic022/token_evidence_matrix.md` bind tokens to evidence and tests; close-pack stubs live in `audit/EPIC-022_MANIFEST.json` and `audit/EPIC-022_close_report.md`.
